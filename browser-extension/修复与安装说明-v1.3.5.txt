浮译浏览器插件 v1.3.5 修复版

适用：支持 Chromium 扩展的浏览器。ZIP 内 manifest.json 位于根目录。

安装：
1. 在原插件的完整设置中导出配置（如果能打开），不要公开包含 Key 的备份。
2. 下载本 ZIP，用浏览器扩展管理页的 ZIP 安装/更新功能选择它；不同浏览器入口名称不同。
3. 新版新增 scripting 权限，用于点开扩展后恢复当前网页的翻译脚本；如浏览器要求确认新增权限，请确认后启用插件。
4. 安装完成后刷新需要翻译的网页。旧标签页中的旧脚本不会因安装更新而自动替换。
5. 页面仍无悬浮按钮时，从浏览器扩展菜单打开“浮译”，会尝试恢复当前普通网页的脚本。
6. 只保留一份浮译处于启用状态，避免旧 ZIP/CRX 同时运行。此包保留原 manifest 公钥，但不同浏览器的 ZIP 安装方式未必复用同一扩展 ID。

此次修复：
- 底部翻译引擎从纯文本改为可点击按钮，打开完整引擎设置。
- 小窗口关闭时清除内联显示状态，避免关闭无效。
- 无 PointerEvent 的旧触屏浏览器避免 touchend 与 click 连续触发导致刚开即关。
- 弹窗先绑定按钮，再加载设置和诊断；后台慢不再阻塞设置按钮。
- 补齐 callback 风格设置读写、脚本注入、创建标签页的 Promise 兼容；后台也加载兼容层。
- 普通网页未注入时尝试恢复内容脚本；失败显示具体原因，浏览器内部页不注入。
- 控制请求超时与翻译请求超时分开，避免多引擎翻译过早被 20 秒消息超时切断。
- 后台诊断复用核心缓存初始化，避免首次诊断创建空数据库后影响翻译缓存。

验证：12 组 Node 检查通过，包含新增的手机 callback API 和小窗口事件回归；所有 JS 语法检查通过。
限制：浏览器测试组件下载失败，未完成真实 Chromium/Quetta 点击测试，也未使用你的 Key 验证在线翻译服务。
