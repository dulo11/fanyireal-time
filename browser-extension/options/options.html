百度翻译凭据池

百度当前官方推荐 APPID + API Key（Bearer）；也兼容 APPID + 传统密钥的 MD5 sign 鉴权。本插件默认请求机器翻译 nmt，避免无意切到大模型翻译。

阿里云翻译凭据池

阿里云使用 AccessKey ID + Secret，扩展在本机按官方 ROA HMAC-SHA1 规则生成签名。Secret 仅保存在浏览器本地设置中，不会提交到 GitHub。
