Microsoft / Azure Translator

网页文本会自动去重、合批；429/5xx/超时会指数退避。可精确隔离的坏文本只重试失败项。

行为

v0.9 会翻译正文和常见属性文字，并保护已经翻好的内容。网页脚本把译文覆盖回原文时会直接恢复，避免重复请求。

术语表 / 固定翻译

术语表：正在读取…

最多 300 条。匹配到的术语会按你指定的译文固定输出，其他片段继续走 Azure / Google；适合人名、品牌名、专业术语和“不希望被翻译”的词。

页面区域排除

在扩展 Popup 里点“选择不翻译区域”，回到网页后直接点击代码块、编辑器、用户名区域等。该网站会记住排除规则；也可以在 Popup 一键清除此网站的全部排除。
