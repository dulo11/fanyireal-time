# 浮译 0.7.2-dev3 测试版

- 面对面连续模式改成真正开放麦克风，不再要求“对方一句 → 我一句 → 对方一句”。
- 使用 Whisper / Qwen3 / Omnilingual / SenseVoice 等本地模型时，模型只加载一次并持续录音，VAD 每次停顿自动切出一句继续识别。
- 同一方可以连续说第二句、第三句；也可以上一句日语、下一句英语，系统会逐句重新识别语言并翻译。
- 连续模式的录音与翻译解耦：上一句正在翻译或朗读时，下一句仍可以继续进入待处理队列，不再因为翻译/TTS 暂停麦克风。
- Android 系统 SpeechRecognizer 仍是逐句识别，但每句结束后立即自动重启下一轮，也不要求双方轮流。
- 连续翻译加入最多 24 句待处理队列，避免对方连续说多句时后面的句子被直接丢掉。
- 自动朗读改成不阻塞持续监听，并增加近期 TTS 回声过滤，降低手机自己朗读的译文再次被识别进去的概率。
- 会话记录由最近 30 轮提高到 50 轮。
- 保留 0.7.2-dev2 的普通实时/ROOT/全局翻译固定目标语言逻辑：任何识别到的外语统一翻译到目标语言；只有面对面对话允许双向。
- 保留全局离线自动识别、Telegram/网页长消息优化、OCR 增强等功能。
- API Key 继续按现有本地方式保存，不做 APK 瘦身。

## 重点测试

1. 面对面 → 连续开放麦克风，选择 Whisper Small/Medium 或 Qwen3-ASR。
2. 让对方连续说两三句日语，中间只正常停顿，不要让本方插话，确认每一句都继续翻成中文。
3. 让对方先说一句日语，再直接说一句英语，确认第二句也能继续翻译，而不是要求本方先说一句。
4. 对方连续说完后，本方连续说两句中文，应都翻到最近识别到的对方语言。
5. 开启“自动朗读译文”，对方在朗读尚未结束时继续说下一句，确认下一句不会因为 TTS 而直接漏掉。

这是 0.7.2 的第三个测试构建，重点修复连续对话仍然实际按一问一答工作的结构问题。
